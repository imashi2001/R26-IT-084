# Optional photos

Drop real photos here to replace the built-in illustrations. Any file that is
missing simply falls back to the animated illustration, so all are optional.

| File | Where it shows | Suggested size |
|------|----------------|----------------|
| `home_hero.jpg` | Welcome screen background (top half) | 1080 × 1350 |
| `login_hero.jpg` | Staff login header | 1080 × 720 |

Use photos you own or that are licensed for reuse (for example Unsplash or
Pexels licence). A dashboard hero image uploaded from the web admin
(`/dashboard/settings`) takes priority over `home_hero.jpg`.
